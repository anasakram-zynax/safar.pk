# Safar.pk

Safar.pk is a full-stack Pakistan tour discovery and demo-booking platform.

## Technology Stack

- Next.js
- NestJS
- Prisma
- PostgreSQL
- Tailwind CSS
- TypeScript

## Roles

- Customer
- Admin

Guests can browse tours without creating an account.

## Project Status

Phase 0: Product alignment and technical decisions.

## Documentation

Project documentation is available in the docs directory.

## Planned Applications

- apps/web: Next.js frontend
- apps/api: NestJS backend
