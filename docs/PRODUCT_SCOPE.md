# Safar.pk MVP Scope

## Product Summary

Safar.pk is a Pakistan-focused tour discovery and demo-booking platform.

Guests can browse published tours and view tour details. Customers can create accounts, select one tour, complete a dummy checkout, and view their bookings. Administrators can create, update, publish, unpublish, and delete tours.

## MVP Features

### Public Features

- Responsive home page
- Animated hero slideshow
- Featured tours
- About section
- Static or seeded customer reviews
- Tour catalog
- Search tours
- Filter by location
- Filter by price
- Sort tours
- Pagination
- URL-based filters
- Tour detail page
- Related tours

### Authentication

- Customer signup
- Customer login
- Logout
- Current-user endpoint
- Forgot-password request
- Email OTP
- OTP verification
- OTP resend with cooldown
- Password reset
- Customer and admin authorization

### Customer Features

- Add one tour to cart
- Replace the existing cart tour
- Remove tour from cart
- Dummy checkout
- Booking confirmation
- Customer booking history
- Customer profile

### Admin Features

- Protected admin dashboard
- Tour listing
- Create tour
- Update tour
- Delete tour
- Publish or unpublish tour
- Upload featured and gallery images
- View basic dashboard statistics
- View bookings

## Out of Scope

The following will not be included in the MVP:

- Real payment gateway
- Multiple tours in one cart
- Multiple travelers
- Seat or departure inventory
- Hotel and transport selection
- Coupons and discounts
- Customer-created reviews
- Tour operator marketplace
- Live chat
- Maps and GPS tracking
- Multiple languages
- Mobile application
- Social login
- Refund processing
- Admin-created admin accounts
